# Mwangaza Electrical Services - Price List App
Android app to list appliances (NO, ITEMS, BRAND). Starts blank; items are saved on the phone automatically.
- Tap the three-bar menu (top right) for: Add Item, Delete Items, Delete All.
- Tap an item row to edit it. Use the search box to filter.

Build: push to GitHub (branch `main`) -> Actions tab -> "Build APK" -> open the run -> download artifact **Mwangaza-Price-List-APK**.
